# DM Security Research

**Independent Cybersecurity Research Laboratory — Argentina**

DM Security Research is an independent cybersecurity research initiative led by **David Menendez**.

## Research focus
- Source-code auditing and application security
- Browser engines and JavaScript runtime behavior
- Protocol and cryptographic workflow analysis
- Reverse engineering and controlled local validation

## Research principles
Research is performed only on owned systems or with explicit authorization. We prioritize reproducible evidence, respect program scope and protect confidential data. Technical hypotheses are not represented as confirmed vulnerabilities without verification.

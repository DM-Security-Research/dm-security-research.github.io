# DM Security Research

**Independent Cybersecurity Research Laboratory — Argentina**

DM Security Research is an independent cybersecurity research initiative led by **David Menendez**. Its work focuses on authorized security assessment, source-code review, reverse engineering, and reproducible experimental validation.

## Research focus
- Application and source-code security
- Browser engines and JavaScript runtime behavior
- Cryptographic protocol and signing-workflow analysis
- Reverse engineering and controlled local laboratories
